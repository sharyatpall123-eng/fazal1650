# د پخوانۍ پروژې اصلاح

د پخوانۍ پروژې ستونزې:

- تکراري components او pages
- غلط یا نیمګړي file names
- inline styles
- hard-coded demo data
- حقیقي backend او database نه موجودېدل
- د Products او Categories غیر ضروري جلا pages
- inconsistent spacing، colors او card sizes
- NaN او overflow حالتونه

په دې نسخه کې functionality په پاک structure کې له سره تنظیم شوې. پخوانی ګډوډ source code مستقیم نه دی ساتل شوی، ځکه د هغه ساتل به ستونزې بېرته انتقال کړې وای. د پخوانۍ پروژې مهم options، card structure او workflows په منظم implementation کې موجود دي.
