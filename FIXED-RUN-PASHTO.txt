د پروژې چلول

1. ZIP Extract کړه.
2. د Extract شوي فولډر په اصلي ځای کې Terminal خلاص کړه.
3. دا قوماندې اجرا کړه:

npm install
npm run dev

که یوازې Frontend چلوې:

cd client
npm install
npm run dev
