AZI WMS WhatsApp Automation Fix

1) Double-click: 4-WHATSAPP-FIX-INSTALL.cmd
2) The fix installs the current upstream whatsapp-web.js source.
3) It uses installed Google Chrome when available.
4) It uses a dedicated LocalAuth profile: .wwebjs_auth_azi
5) Existing WhatsApp session folders are NOT deleted by the installer.
6) On first use of the new profile, scan the QR once.
7) Keep the server running for scheduled WhatsApp automation.

Important: WhatsApp Web automation is unofficial and WhatsApp can change its web client.
